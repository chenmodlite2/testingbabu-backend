How it works

The app reads two files from GitHub Pages:

keys.json — maps sha256(key) to {active,label,expiry,note,maxDevices,devices,reason}. Only hashes are stored, so leaking the file never reveals a usable key.

config.json — version gate, update url and the security switches.

Saving here commits to the repository through the GitHub Contents API. GitHub Pages republishes automatically, and open apps pick the change up within seconds.

Key format

Keys are case-insensitive and spaces / dashes are ignored when hashing, so chen-ab12-cd34 and CHENAB12CD34 are the same key.
